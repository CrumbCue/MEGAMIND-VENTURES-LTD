# Megamind Ventures Ltd website

Static site (HTML, CSS, JS). No build step.

## Files
- `index.html` – all page content
- `style.css` – colours are at the top (`:root`)
- `script.js` – mobile menu and WhatsApp quote form (set `WHATSAPP`)
- `assets/` – put your photos and logos here

## Publish on GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload all files in this folder (keep `.nojekyll`).
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: `main`, folder `/ (root)` > Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Before launch
- Replace the photo and logo placeholders with real images in `assets/`.
- Only list clients who agreed to it.
